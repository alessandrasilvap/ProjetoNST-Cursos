# 🎓 Projetos NST Cursos

Coleção de projetos de Front-End desenvolvidos durante os cursos da **Node Studio Treinamentos**. Cada pasta é um site completo, criado do zero com HTML e CSS, e mostra a evolução dos estudos: do layout clássico com `float`, passando pelo design responsivo *mobile first*, até layouts modernos com **Flexbox**.

## 📂 Projetos

### 1. NodeShop — Loja de Informática
📁 [`Projeto1-HTMLeCSS`](./Projeto1-HTMLeCSS)

<img width="1365" alt="Página da NodeShop" src="https://github.com/user-attachments/assets/b7914ba7-fe38-49b9-83f5-7330c7010d3e" />

Site institucional de uma loja de informática, com cabeçalho com campo de busca, menu de navegação, ícones de redes sociais, seção "Sobre Nós", mapa do Google Maps incorporado, contatos e newsletter.

**O que pratiquei:**
- Estrutura semântica com `header`, `nav`, `main`, `article`, `aside`, `section` e `footer`
- Layout em colunas usando `float`
- Reset de CSS e estilização de formulários
- Ícones com Font Awesome e efeitos de `:hover`
- Incorporação de mapa com `iframe`

### 2. NodeProp — Agência de Soluções Digitais
📁 [`Projeto2-DesignResponsivo`](./Projeto2-DesignResponsivo)

<img width="1365" alt="Página da NodeProp" src="https://github.com/user-attachments/assets/c8cab0cf-34cd-43e3-898a-5f94daac8dcb" />

Landing page de uma agência de publicidade, com banner de destaque, cards de serviços, newsletter e menu que vira um painel em tela cheia no celular.

**O que pratiquei:**
- Abordagem **Mobile First**
- Media queries em quatro pontos de quebra (480px, 768px, 960px e 1280px)
- Troca de logo conforme o tamanho da tela
- Classes utilitárias reaproveitáveis (`.container`, `.radius`, `.bg-gradient`…)
- Gradientes com `linear-gradient`
- Menu mobile com abrir/fechar usando **jQuery**

### 3. Hotel Paraíso — Itacaré
📁 [`Projeto3-CSSFlexivel`](./Projeto3-CSSFlexivel)

<img width="1365" alt="Página do Hotel Paraíso" src="https://github.com/user-attachments/assets/1840227e-8455-465d-8c60-d3fb7d74b38b" />

Site de um hotel em Itacaré (BA), com hero ocupando a tela inteira, galeria de fotos, seção de características com ícones, newsletter e rodapé com redes sociais.

**O que pratiquei:**
- Layout completo com **Flexbox** (`justify-content`, `align-items`, `flex-direction`, `flex-wrap`, `flex-basis`)
- Hero em tela cheia com `min-height: 100vh`
- Galeria em grade com tamanhos alternados (`.small` e `.large`)
- Responsividade com media queries que reorganizam o layout em telas menores

## 🚀 Como executar

Os projetos não precisam de instalação nem de build: são apenas HTML e CSS.

```bash
# Clone o repositório
git clone https://github.com/SEU-USUARIO/ProjetoNST-Cursos.git

# Entre na pasta do projeto que quiser ver
cd ProjetoNST-Cursos/Projeto3-CSSFlexivel
```

Depois é só abrir o arquivo `index.html` no navegador. Se usar o VS Code, a extensão **Live Server** atualiza a página automaticamente a cada alteração.

> Os ícones e fontes são carregados de CDNs (Font Awesome e Google Fonts), então é preciso estar conectado à internet para ver a página completa.
